Install

VS Code / Cursor Extension

One-click lock/unlock from the status bar. No terminal needed.

  1. Download .vsix from Releases
  2. In your editor: Extensions → ... → Install from VSIX...
  3. Or from terminal:
# VS Code
code --install-extension dotenvup-0.4.0.vsix

# Cursor
cursor --install-extension dotenvup-0.4.0.vsix

CLI

For terminal workflows, CI/CD, and AI agents.

npm install -g @dotenvup/cli

up init            # generate keypair
up import .env     # encrypt → .env.up
up lock            # delete plaintext
up unlock 5m       # decrypt for 5 min
up run -- npm start # no file on disk

Open Standard — DotEnvUp v1

The .env.up format is a published open standard. X25519 + XChaCha20-Poly1305 encryption, multi-recipient support, CI/CD-ready, and lossless roundtrip of comments and structure.

Read the Format Specification

🔐 Zero-knowledge, zero-trust

No server, no cloud. Your keys live only on your machine (~/.dotenvup/identity). We never see your secrets — encrypt and decrypt locally.

🔒 Encrypted at Rest

Values, comments, and structure are encrypted on disk using XChaCha20-Poly1305. No more plaintext secrets in your repo.

📝 Comments Preserved

Your # Database headers, blank lines, and commented-out secrets survive the encrypt/decrypt roundtrip perfectly.

⚡️ Zero Code Changes

Works with existing dotenv libraries. Just up unlock to work, and up lock when done. Or use up run.

📍 Metadata

See who changed a key and when, without decrypting it. The "half-open envelope" format keeps context visible.
